## Program Description
The **Student Grade Calculator** is an academic utility created to help students and instructors quickly evaluate student performance across different coursework subjects. 

Key features include:
- Interactive console input for subject grades.
- Automatic average computation.
- Comprehensive letter grade classification (`A`, `B`, `C`, `D`, `F`).
- Pass/Fail evaluation remarks with performance designations.
- Formatted tabular terminal output.

---

## Grading Scale Reference

| Score Range | Letter Grade | Remark |
| :--- | :---: | :--- |
| **90.00 – 100.00** | **A** | Passed (Excellent) |
| **80.00 – 89.99** | **B** | Passed (Good) |
| **75.00 – 79.99** | **C** | Passed (Satisfactory) |
| **70.00 – 74.99** | **D** | Passed (Conditional) |
| **Below 70.00** | **F** | Failed |

## How to Run the Program

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/student-grade-calculator.git
   cd student-grade-calculator
   ```

2. **Run the script:**
   - On Windows:
     ```powershell
     python grade_calculator.py
     ```
   - On macOS/Linux:
     ```bash
     python3 grade_calculator.py
     ```

3. **Follow the interactive prompts:**
   - Type the student name when prompted.
   - Enter numeric scores (between `0` and `100`) for each subject.
   - View the formatted grade summary in your terminal.
